# VCDS.de — Rebuild

Website der Auto-Intern GmbH für Ross-Tech VCDS Diagnoseadapter.

## Tech Stack
- **Next.js 14** (App Router)
- **Tailwind CSS**
- **TypeScript**
- Quicksand (Google Font via next/font, DSGVO-konform)

## Seiten
- `/` — Startseite
- `/ueber-vcds` — Über VCDS
- `/produkte` — Produktübersicht
- `/faq` — FAQ mit Accordion
- `/download` — Downloads mit Tabs
- `/kontakt` — Kontaktformular + Team
- `/quickstart` — Interaktiver Setup-Wizard
- `/fachhaendler` — Fachhändler DACH
- `/impressum` — Impressum
- `/datenschutz` — Datenschutz

## Entwicklung
```bash
npm install
npm run dev
```

## Deploy
Automatisch via Vercel bei Push auf `main`.
